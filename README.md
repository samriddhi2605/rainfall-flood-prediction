# Rainfall Based Flood Risk Prediction

This project uses historical rainfall data from Kerala to classify rainfall conditions into normal and high-risk categories using a Random Forest model.

## Method

- Cleaned and prepared the rainfall data
- Used monthly rainfall from January to December
- Created rainfall risk categories
- Trained a Random Forest classifier
- Evaluated the model using accuracy, precision, recall and F1-score

## Results

- Accuracy: 79.17%
- Precision: 66.67%
- Recall: 33.33%
- F1 Score: 44.44%

July rainfall was one of the important features in the model.

## Example

The model predicted **High Flood Risk** for the sample rainfall values entered in the notebook, with a high-risk probability of **57.62%**.

## Tools

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn and Google Colab.

## Note

This is a rainfall-based machine learning project and is not an actual flood
warning system. Real flood prediction would require additional information
such as river levels, soil moisture, terrain and real-time weather data.
